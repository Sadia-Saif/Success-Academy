# Success Academy

A Next.js interactive academy for AI automation, B2B sales, executive English and leadership. Features blue-purple animated dashboard, curated external tutorial library, masterclasses, labs, roleplays and locally stored progress.

## Run

`npm install && npm run dev`

## Limitations

The 360-day-by-track navigation uses reusable case-study lesson templates, not 360 fully authored in-depth lessons. Linked tutorials belong to third-party publishers. The speaking coach uses optional browser speech recognition and heuristic feedback, not a connected conversational AI model. Progress is saved locally.
